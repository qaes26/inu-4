# 🌱 المساعد البيئي الذكي - حملة «بيئتنا لوحتنا»
### جامعة إربد الأهلية - المملكة الأردنية الهاشمية

مشروع متكامل يجمع بين موقع تعريفي عصري لحملة النظافة والاستدامة، ومساعد ذكاء اصطناعي تفاعلي حقيقي متصل بنموذج ذكاء اصطناعي متطور باللغة العربية، وفق أعلى معايير الأمان وحماية المفاتيح البرمجية.

---

## 📁 هيكلية المشروع

```text
رابعة نضافة/
├── server.js              # خادم Express الآمن والـ API Endpoints
├── package.json           # الحزم والاعتماديات
├── .env                   # ملف متغيرات البيئة السري والمفتاح البرمجي
├── .env.example           # نموذج ملف الإعدادات للمطورين
├── .gitignore             # منع رفع المفاتيح البرمجية ومجلد node_modules
├── start.bat              # سكربت تشغيل سريع بنقرة واحدة (Windows)
├── public/
│   ├── index.html         # الموقع الرئيسي لحملة بيئتنا لوحتنا
│   ├── chatbot.css        # التنسيقات الفاخرة للودجت والخط العربي Tajawal
│   ├── chatbot.js         # محرك الشات بوت والاتصال بالسيرفر
│   └── images/            # المعرض المصور وبوسترات الحملة الرسمية
└── node_modules/          # مكتبات Node.js
```

## 🚀 طريقة التشغيل السريعة

### 1. المتطلبات:
- تثبيت **Node.js** (إصدار 18 فما فوق).

### 2. تشغيل الخادم:
يمكنك ببساطة النقر المزدوج على ملف:
```cmd
start.bat
```
أو عبر سطر الأوامر (Terminal / PowerShell):
```bash
npm start
```

### 3. فتح الموقع في المتصفح:
توجه إلى الرابط التالي:
```text
http://localhost:3000
```

## 🔒 الأمان وحماية مفتاح API

1. **الخادم الآمن (Backend Isolation):**
   - لا يتم إرسال أو تضمين مفتاح الـ API داخل كود الـ HTML أو الـ JavaScript الذي يصل إلى المتصفح أبداً.
   - الاتصال بالذكاء الاصطناعي يتم حصرياً عبر الـ Endpoint الآمن `POST /api/chat`.
2. **حماية من كثرة الطلبات (Rate Limiting):**
   - تم تطبيق حماية بمعدل 20 طلباً في الدقيقة لكل IP لمنع الإفراط في الاستهلاك.
3. **حماية الترويسات (Helmet & CSP):**
   - تطبيق إعدادات حماية صارمة تمنع هجمات XSS و Clickjacking مع السماح بالخطوط والصور.
4. **الـ System Prompt المحمي:**
   - التوجيه الأساسي للمساعد مخزن على الخادم فقط ولا يمكن للمستخدمين التلاعب به أو استخراجه.

## 🤖 إعدادات الذكاء الاصطناعي (.env)

قم بإنشاء ملف `.env` (أو استخدم النموذج `.env.example`) وضع مفتاحك:
```env
AI_API_KEY=your_api_key_here
AI_MODEL=openai/gpt-oss-120b
PORT=3000
ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
```
- يدعم الخادم كلاً من مفاتيح **Groq** فائقة السرعة المتوافقة مع OpenAI API (`gsk_...`) ومفاتيح **OpenAI** الرسمية (`sk-...`).

## 🌟 مميزات المساعد البيئي:
- **فهم عميق للهجة الأردنية والفصحى:** يجيب بأسلوب دافئ وبسيط ومختصر.
- **التوجيه لنموذج الإبلاغ:** عند السؤال عن مكان غير نظيف، يوجه مباشرة إلى نموذج الإبلاغ في الصفحة `#report-section`.
- **أزرار الأسئلة السريعة:** أزرار جاهزة لأهم استفسارات الحملة.
- **الاحتفاظ بالسياق:** متابعة المحادثة وفهم السياق السابق خلال الجلسة.
- **إعادة المحاولة التلقائية:** معالجة انقطاع الاتصال ومحاولة الإرسال مجدداً دون إزعاج المستخدم.
